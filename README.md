# Байланыс

Телефон мен Windows ноутбугіне арналған интерфейсті алдымен **GitHub Pages арқылы браузерде тексереміз**. Бұл кезеңде APK/EXE жасалмайды.

- [Интерфейсті ашу](https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/)
- [Телефон көрінісі](https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/ui/?platform=android)
- [Ноутбук көрінісі](https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/ui/?platform=windows)

Қою фон, күлгін және ашық жасыл екпіндер, жеңіл анимациялар және суреттің өзінен жасалған бөлшектерге ыдырау әсері бар. «Ноутбук» көрінісіндегі **Эффектіні сынап көру** батырмасы сынақ суретін бірден ашады.

## Қалай тексеруге болады

1. «Телефон» көрінісін ашып, «Қосылу» → «Демо байланысты қосу» батырмасын бас.
2. Мәтін/код енгіз немесе PNG/JPEG суретін таңда да, «Демо жіберу» батырмасын бас.
3. Жоғарыдан «Ноутбук» көрінісіне ауыс. Жіберілген мазмұн осы бетте көрсетіледі.
4. «Осы құрылғының буферіне көшіру», жіберу тарихы және байланысты ажырату әрекеттерін тексер.

**Бұл — интерфейс демосы.** Телефон мен ноутбук арасында нақты байланыс орнатылмайды. Таңдалған мазмұн серверге жіберілмейді; бетті жаңартқанда демо мазмұн мен тарих тазарады. Буферге көшіру браузер рұқсатына байланысты.

GitHub Pages репозиторийдің `main` тармағындағы түбірінен жарияланады. Түбірдегі `index.html` сұралған көріністі сақтап, `ui/` бетін ашады. `.nojekyll` статикалық файлдарды өзгеріссіз береді. Егер Pages кейін өшірілсе, **Settings → Pages → Deploy from a branch → main → / (root)** таңда.

## Жергілікті тексеру

```sh
npm install --ignore-scripts
npx playwright install --with-deps chromium
npm run screenshots
```

Бұл команда браузерде навигацияны, екі көріністі, демо жұптасуды, мәтін/сурет жіберуді, буферге көшіруді, ажыратуды және телефон өлшеміндегі орналасуды тексереді. Нақты браузер скриншоттары `docs/screenshots/` ішіне түседі. `Interface screenshots` workflow runner ішінде бар Google Chrome арқылы тексеруді іске қосып, скриншоттарды artifact ретінде сақтайды.

Native bridge кодтары болашақ APK/EXE үшін сақталған; қазір тасымал жүйесі мен қолданба құрастыру workflow-ы қосылған жоқ.
