# Екі экран

Телефон мен ноутбук арасында мәтін, сурет және Android телефонының экранын жіберуге арналған қосымша. Телефонда тұрақты төменгі мәзір, ноутбукта бүйір мәзір бар.

Сайт: https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/ui/

## Қалай қосылады

1. Ноутбук пен телефонда сайтты аш. Браузер құрылғы түрін өзі анықтайды; `platform` параметрі тек болашақ native клиенттер үшін қолданылады.
2. Ноутбуктың «Құрылғылар» бетінде QR және жеке `WP-` коды пайда болады.
3. Телефонда «Құрылғылар» → «QR сканерлеу» батырмасын бас. Камераға рұқсат беріп QR-ды оқыт немесе кодты қолмен енгіз. QR сілтемесін телефон камерасымен ашсаң да жұптастыру басталады.
4. Ноутбукта қосылу сұрауын раста. Телефонның «Ортақ буфер» бетінен мәтін не сурет жібер; ноутбукта оны қабылдап, қажет болса жүйелік буферге көшір.

## Телефонды басқару

1. [Android қолданбасының Actions бетіндегі](https://github.com/jjjjjjjjjjjjjjae-hub/windows-phone-/actions/workflows/android.yml) соңғы сәтті `Android app` іске қосылуынан `EkiEkran-Android-APK` артефактын жүкте. ZIP ішінен `app-debug.apk` файлын шығарып, Android телефоныңа орнат. Бұл сынақ нұсқасы; бұрынғы CI debug APK-ның қолтаңбасы бөлек болуы мүмкін, сондықтан жаңасы орнатылмаса ескісін өшір.
2. Ноутбукта сайтты, телефонда орнатылған **Екі экран** қолданбасын ашып, QR немесе код арқылы жұптастыр.
3. Телефонда **«Root рұқсатын сұрау»** батырмасын бас. Root орнатылған құрылғыда Magisk бұрынғы нұсқаларында сұрау көрсетеді; жаңа Magisk 31.1 нұсқасында рұқсатты **Magisk → Superuser** бөлімінен «Екі экран» қолданбасына алдын ала беріп, батырманы қайта бас. Root болмаса «Басқару рұқсатын ашу» арқылы Android арнайы мүмкіндіктеріндегі «Екі экран» қызметін қос. Ол экран мәтінін оқымайды; тек рұқсат етілген сеанста қимылдарды орындайды.
4. Ноутбукта «Басқаруды сұрау» батырмасын бас. Телефонда сұрауды раста, содан кейін Android экранды бөлісу диалогында **бүкіл экранды** таңда. Ноутбукта экран пайда болған соң басып, сырғытып, «Артқа», «Басты бет», «Соңғы» батырмаларын қолдан.
5. Телефондағы тұрақты экран бөлісу хабарламасынан немесе сайттағы «Тоқтату» батырмасынан сеансты аяқта.

Сайтты тек телефон браузерінде ашу толық экранды басқаруға жетпейді: экранды көрсетуге Android жүйелік рұқсаты, ал қимылдарға root немесе арнайы мүмкіндік қызметі керек. Қолданба root-ты тек рұқсат етілген экран бөлісу сеансында экранды басу, сырғыту және үш жүйелік әрекет үшін қолданады; еркін shell командасын сайттан қабылдамайды. Әр экран бөлісу сеансын телефон иесі жеке растайды.

Төменгі мәзір тек телефонда көрінеді және барлық үш бетте тұрақты тұрады. Қосылған құрылғының атауы мен күйі нақты байланыс оқиғасынан кейін көрсетіледі. «Жіберу тарихы» соңғы 10 әрекетті осы сеансқа ғана сақтайды.

## Шектеулер

Сайт GitHub Pages-та, Android қолданбасы оның қорғалған бетін WebView арқылы ашады. PeerJS Cloud жұптастыруға сигнал сервері ретінде қажет, ал мәлімет WebRTC DataChannel арқылы жіберіледі. Екі құрылғыда интернет керек; бір Wi-Fi міндетті емес. Кейбір желілерде TURN релесіз P2P байланысы орнамауы мүмкін. Камераға HTTPS және рұқсат қажет. PNG/JPEG сурет көлемі 20 МБ дейін. Браузер жүйелік буферге автоматты жаза алмайды; ноутбукта «Буферге көшіру» батырмасын бас. Экран Android-та ені 480 пиксельге дейін ықшамдалып JPEG форматында жіберіледі; келесі кадр ноутбук алдыңғысын көрсеткен соң өңделеді. Бұл жоғары жылдамдықтағы ойын ағынына арналмаған.

## Тексеру

`npm install` және `npm run screenshots` пәрмендері Chrome/Playwright бар ортада телефон және ноутбук көріністерін, жұптастыру, мәтін тасымалы, буфер, тарих және ажыратуды тексереді. GitHub Actions осы тексерісті `main` тармағына өзгеріс түскенде іске қосып, скриншоттарды artifact ретінде сақтайды.
