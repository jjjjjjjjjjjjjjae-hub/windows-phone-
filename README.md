# Windows ↔ Phone

GitHub Pages-та телефон мен ноутбук арасындағы **браузерлік онлайн дерек алмасуды** сынайтын сайт. APK және EXE әзірге жасалмайды.

- Сайт: https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/ui/
- Ноутбук: https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/ui/?platform=windows
- Телефон: https://jjjjjjjjjjjjjjae-hub.github.io/windows-phone-/ui/?platform=android

## Қалай қосылады

1. Ноутбук пен телефонда сайтты аш. Құрылғы түрі автоматты анықталады, URL-дегі platform параметрі браузерде ескерілмейді.
2. Ноутбуктың «Құрылғылар» бөлімінде **QR-код** және жеке **WP-** коды шығады.
3. Телефон камерасымен ноутбуктағы QR-кодты сканерле. Ашылған сайт құрылғыны автоматты түрде табуға тырысады. QR жұмыс істемесе, **WP-** кодын телефонға қолмен енгізуге болады.
4. Ноутбукта шыққан қосылу сұрауын міндетті түрде раста. Қосылғаннан кейін телефон мәтін немесе PNG/JPEG суретін жіберіп, ноутбук экранында қабылдай алады.
5. Ноутбуктағы «Буферге көшіру» батырмасы арқылы мәтін не суреттің көшірмесін жүйелік буферге алуға болады. Браузер автоматты түрде буферге жазбайды.

Бұл сайт PeerJS 1.5.5 + WebRTC DataChannel пайдаланады. PeerJS Cloud — сыртқы сигнал беру сервері; сондықтан «сервер мүлде жоқ» деу дұрыс емес. Жіберілген файлдар қолданбаның жеке серверіне жүктелмейді, файл мазмұны WebRTC арнасымен тасымалданады. P2P байланыс кейбір ұялы операторлар мен NAT/брандмауэрлер арасында TURN релесіз іске аспауы мүмкін. Екі құрылғыда да интернет қажет, бір Wi-Fi міндетті емес.

Сурет PNG/JPEG, 20 МБ дейін. Жіберу сәтінде бөлшектерге ыдырау анимациясы бар. Беттен шыққан соң сеанс тоқтайды; тарих тұрақты сақталмайды. Бұл әзірге **браузерлік эксперимент**, үздіксіз синхрондау, жергілікті офлайн режим, толық EXE/APK немесе автоматты жүйелік clipboard синхрондау емес.

## QR-сілтеме қауіпсіздігі

QR-код пайдаланушының ағымдағы GitHub Pages мекенжайын және кездейсоқ 16 таңбалы жұптастыру кодын қамтиды. Ол арқылы дерек тікелей жіберілмейді. Жұптастыру тек ноутбуктағы «Рұқсат беру» батырмасы басылған соң аяқталады. QR-сілтемені бөгде адамға бөліспе.

## Өзгерістер

- Алтын логотип фиолет түске ауыстырылып, көлденең созылды; брендтегі «Байланыс» атауы алынып тасталды.
- Windows-та қабылдау және жұптау көрінісі, телефонда жіберу көрінісі автоматты ашылады.
- Рұқсат берілмеген қосылым қабылданбайды, код кездейсоқ генерирленеді.
- Құрылғылар арасында мәтін мен суретті нақты жіберу логикасы қосылды.

## Тексеру

GitHub Pages негізгі `main` тармағындағы `/` түбірінен шығады. Браузер кэші ескі нұсқаны көрсетсе, Windows-та Ctrl+Shift+R жаса, телефонда сайт кэшін тазала.
